# PES-15.1.0 — نتایج آزمون تفکیک مراحل Task

تاریخ: ۲۰ نوامبر ۲۰۲۶  
محصول هدف: موتور مستقل Project Evolution Standard (نه Build یا Runtime برنامه Portfolio Builder).

## آنچه آزمون شد

- ۱۰۳ تست واحد/Integration در موتور PES-15.1 شامل ۷۳ تست هسته قبلی و ۳۰ تست اختصاصی مربوط به مراحل و سازگاری.
- ۷ تست آداپتور Portfolio Builder در حالت ایزوله و روی نمونه PES-14.
- مهاجرت کپی PES-14 و ایجاد DB مستقل در SQLite با CAS، با حفظ کامل داده‌های نسخه قبلی.
- تست تفکیک: `prioritization=completed` برای Task اصلاحی هرگز `implementation=completed`، `verification=passed` یا `acceptance=accepted` نمی‌کند.
- انجام Implementation فقط خروجی اصلاح را ثبت می‌کند؛ Verification و Acceptance همچنان مستقل هستند.
- تسک‌های تاریخی که پیشرفت قابل اثبات ندارند، با حالت نامعلوم نمایش داده می‌شوند، حتی اگر `status=completed` قدیمی داشته باشند.
- به‌روزرسانی هر مرحله بدون تغییر وضعیت دیگر مراحل و بدون بازنویسی فایل منبع.
- جلوگیری از ادعای تکمیل بی‌دلیل؛ الزام رکورد Verification مستقل برای Pass و Acceptance برای تأیید مالک.
- حفظ تاریخچه و ارجاعات شواهد در بازگشایی مرحله و الزام دلیل بازگشایی.
- نمونه JSON: `examples/PES-15-stage-isolation-example.json` معتبر است؛ اولویت‌بندی تکمیل شده ولی اصلاح هنوز نشده است.
- نمایش HTML آزمایشیِ فقط‌خواندنی با پنج بخش مستقل: `examples/task-workflow-sections.html`.

## محدودیت و مرز صداقت

تست‌های موتور روی Fixture مستقل و داده آزمایشی انجام شده‌اند؛ هیچ Build/Test برای نرم‌افزار اصلی Portfolio Builder اجرا نشده است. صحت فنی ادعای تغییر سورس، واقعاً اجراشدن یک تست و اصالت تأیید مالک از روی فیلدهای JSON به‌تنهایی قابل اثبات نیست؛ سندهای بیرونی و بازبینی انسانی لازم است. تست مهاجرت کل جدیدترین Snapshot پروژه از GitHub نیز جزو این انتشار نبوده است.

## همزیستی نسخه‌ها

- PES-14 تغییر نکرده؛ مهاجرت فقط با درخواست صریح و کپی جدید انجام می‌شود.
- PES-15.0.0 تغییر نکرده؛ `upgrade-v15` یک کپی جدید PES-15.1.0 تولید می‌کند.
- هیچ تغییر یا Commit به شاخه‌های GitHub، فایل‌های برنامه، HTML اصلی یا پایگاه‌داده واقعی Portfolio Builder انجام نشده است.

نتیجه تست نهایی و هش Manifest در همان بسته بعد از ساخت محاسبه و کنترل می‌شود.

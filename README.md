# Project Evolution Standard (PES)

Official source repository for versioned Project Evolution Standard releases.

Each published release is preserved in a separate directory:

- `releases/PES-13.0.0/`: legacy portable standard.
- `releases/PES-14.0.0/`: PES-14 portable standard.
- `releases/PES-15.0.0/`: standalone implementation.
- `releases/PES-15.1.0/`: independent task-phase update.

Files from earlier releases are immutable. Releases are published in chronological Git commits; no ZIP files are tracked. Consumers must pin to a precise release path or tag.
